# Fonts used by Sovereign

All five families are licensed under the SIL Open Font License 1.1, which allows use, embedding and redistribution on the web.
The files are latin-subset WOFF2 builds from the Fontsource packages on npm, self-hosted so the app works offline. The license text for each family sits next to the font files (`LICENSE-*.txt`).

| Family | Used for | Copyright |
|---|---|---|
| Inter Tight (700, 800) | The Modernist | The Inter Project Authors |
| Playfair Display (400, 400 italic) | The Editorial | The Playfair Display Project Authors |
| Instrument Serif (400, 400 italic) | The Intellectual | The Instrument Serif Project Authors |
| Cinzel (500, 600) | The Institution (capitals) | The Cinzel Project Authors |
| Cormorant Garamond (400, 500 italic) | The Institution (italic secondary) | The Cormorant Project Authors |
